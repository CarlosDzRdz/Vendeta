PRÁCTICA 1: CONFIGURACIÓN DE ANDROID STUDIO Y EMULADORES

Objetivo:
    Instalar y configurar Android Studio para el desarrollo de aplicaciones móviles,
    así como crear y configurar emuladores de dispositivos Android.

Desarrollo:

1. Instalación de Android Studio
    
    Se descargó Android Studio desde el sitio oficial de Android Developers 
    (https://developer.android.com/studio). La versión instalada fue la más 
    reciente disponible (Hedgehog | 2023.1.1 o posterior).
    
    Pasos realizados:
    - Descarga del instalador para el sistema operativo correspondiente
    - Ejecución del instalador con privilegios de administrador
    - Selección de componentes: Android SDK, Android SDK Platform, Android Virtual Device
    - Configuración de la ubicación del SDK: C:\Users\[Usuario]\AppData\Local\Android\Sdk
    - Finalización de la instalación

2. Configuración Inicial del SDK

    Una vez instalado Android Studio, se procedió a configurar el SDK:
    
    - Acceso a: File → Settings → Appearance & Behavior → System Settings → Android SDK
    - Instalación de SDK Platforms:
        * Android 14.0 (API Level 34)
        * Android 13.0 (API Level 33)
        * Android 12.0 (API Level 31)
    
    - Instalación de SDK Tools:
        * Android SDK Build-Tools
        * Android Emulator
        * Android SDK Platform-Tools
        * Intel x86 Emulator Accelerator (HAXM installer)

        - VM Heap: 512 MB
        - Internal Storage: 2048 MB

    class BluetoothManager(private val context: Context) {
        
        private val bluetoothAdapter: BluetoothAdapter? = 
            BluetoothAdapter.getDefaultAdapter()
        
        fun isBluetoothEnabled(): Boolean {
            return bluetoothAdapter?.isEnabled ?: false
        }
        
        fun getPairedDevices(): Set<BluetoothDevice>? {
            return bluetoothAdapter?.bondedDevices
        }
        
        fun startDiscovery() {
            if (bluetoothAdapter?.isDiscovering == true) {
                bluetoothAdapter.cancelDiscovery()
            }
            bluetoothAdapter?.startDiscovery()
        }
    }

    Código para envío de datos:

    class BluetoothDataTransfer(private val device: BluetoothDevice) {
        
        private val uuid = UUID.fromString(
            "00001101-0000-1000-8000-00805F9B34FB"
        )
        
        fun sendData(data: String) {
            Thread {
                try {
                    val socket = device.createRfcommSocketToServiceRecord(uuid)
                    socket.connect()
                    
                    val outputStream = socket.outputStream
                    outputStream.write(data.toByteArray())
                    outputStream.flush()
                    
                    socket.close()
                } catch (e: Exception) {
                    e.printStackTrace()
                }
            }.start()
        }
    }

    class FirebaseDataSync {
        
        private val database = Firebase.database
        private val messagesRef = database.getReference("messages")
        
        fun sendMessage(deviceId: String, message: String) {
            val messageData = hashMapOf(
                "deviceId" to deviceId,
                "message" to message,
                "timestamp" to System.currentTimeMillis()
            )
            
            messagesRef.push().setValue(messageData)
        }
        
        fun listenForMessages(callback: (String) -> Unit) {
            messagesRef.addChildEventListener(object : ChildEventListener {
                override fun onChildAdded(
                    snapshot: DataSnapshot, 
                    previousChildName: String?
                ) {
                    val message = snapshot.child("message")
                        .getValue(String::class.java)
                    message?.let { callback(it) }
                }
                
                override fun onChildChanged(
                    snapshot: DataSnapshot, 
                    previousChildName: String?
                ) {}
                
                override fun onChildRemoved(snapshot: DataSnapshot) {}
                override fun onChildMoved(
                    snapshot: DataSnapshot, 
                    previousChildName: String?
                ) {}
                override fun onCancelled(error: DatabaseError) {}
            })
        }
    }

3. Módulo Mobile - Código de Sincronización

    MainActivity.kt (Mobile):

    class MobileMainActivity : ComponentActivity() {
        
        private lateinit var dataClient: DataClient
        private lateinit var messageClient: MessageClient
        
        override fun onCreate(savedInstanceState: Bundle?) {
            super.onCreate(savedInstanceState)
            
            dataClient = Wearable.getDataClient(this)
            messageClient = Wearable.getMessageClient(this)
            
            setContent {
                MobileApp(
                    onSendToWear = { data -> sendDataToWear(data) }
                )
            }
        }
        
        private fun sendDataToWear(data: String) {
            val putDataReq = PutDataMapRequest.create("/data_path").apply {
                dataMap.putString("key_message", data)
                dataMap.putLong("timestamp", System.currentTimeMillis())
            }.asPutDataRequest().setUrgent()
            
            dataClient.putDataItem(putDataReq).addOnSuccessListener {
                Log.d("Mobile", "Data sent to wear device")
            }
        }
        
        private fun sendMessageToWear(message: String) {
            val nodeClient = Wearable.getNodeClient(this)
            
            nodeClient.connectedNodes.addOnSuccessListener { nodes ->
                nodes.forEach { node ->
                    messageClient.sendMessage(
                        node.id,
                        "/message_path",
                        message.toByteArray()
                    )
                }
            }
        }
    }

4. Módulo Wear - Código de Recepción

    MainActivity.kt (Wear):

    class WearMainActivity : ComponentActivity(), DataClient.OnDataChangedListener {
        
        private lateinit var dataClient: DataClient
        private val messageFlow = MutableStateFlow("")
        
        override fun onCreate(savedInstanceState: Bundle?) {
            super.onCreate(savedInstanceState)
            
            dataClient = Wearable.getDataClient(this)
            
            setContent {
                WearApp(messageFlow = messageFlow)
            }
        }
        
        override fun onResume() {
            super.onResume()
            dataClient.addListener(this)
        }
        
        override fun onPause() {
            super.onPause()
            dataClient.removeListener(this)
        }
        
        override fun onDataChanged(dataEvents: DataEventBuffer) {
            dataEvents.forEach { event ->
                if (event.type == DataEvent.TYPE_CHANGED) {
                    event.dataItem.also { item ->
                        if (item.uri.path == "/data_path") {
                            DataMapItem.fromDataItem(item).dataMap.apply {
                                val receivedMessage = getString("key_message")
                                receivedMessage?.let {
                                    messageFlow.value = it
                                }
                            }
                        }
                    }
                }
            }
        }
    }

    @Composable
    fun WearApp(messageFlow: StateFlow<String>) {
        val message by messageFlow.collectAsState()
        
        Box(
            modifier = Modifier
                .fillMaxSize()
                .background(MaterialTheme.colors.background),
            contentAlignment = Alignment.Center
        ) {
            Column(
                horizontalAlignment = Alignment.CenterHorizontally
            ) {
                Text(
                    text = "Mensaje recibido:",
                    style = MaterialTheme.typography.caption1,
                    color = Color.White
                )

                    text = message.ifEmpty { "Sin mensajes" },
                    style = MaterialTheme.typography.title3,

5. Sincronización Bidireccional

    Código para respuesta desde Wearable:

    class WearMessageService : WearableListenerService() {
        
        override fun onMessageReceived(messageEvent: MessageEvent) {
            if (messageEvent.path == "/request_data") {
                sendResponseToMobile()
            }
        }
        
        private fun sendResponseToMobile() {
            val nodeClient = Wearable.getNodeClient(this)
            
            nodeClient.connectedNodes.addOnSuccessListener { nodes ->
                nodes.forEach { node ->
                    val messageClient = Wearable.getMessageClient(this)
                    messageClient.sendMessage(
                        node.id,
                        "/response_path",
                        "Respuesta desde wearable".toByteArray()
                    )
                }
            }
        }
    }

    Declaración del servicio en AndroidManifest.xml (Wear):

    <service android:name=".WearMessageService">
        <intent-filter>
            <action android:name="com.google.android.gms.wearable.MESSAGE_RECEIVED" />
            <data android:scheme="wear" android:host="*" 
                  android:pathPrefix="/request_data" />
        </intent-filter>
    </service>
